1. Project Overview & Executive Summary

This report documents the step-by-step methodology, architecture, and AI-assisted workflows used to replicate the ImportNow concept website. The goal was to build a 100% faithful, high-performance replica from scratch, encompassing all 11 landing page sections, custom 3D WebGL interactive simulations (interactive globe and ocean voyage), dynamic blog system, and responsive UI engine.

Rather than relying on heavy monolithic site-builders or bloated frameworks, the platform was engineered using clean modern standards (HTML5, modern CSS3, ES modules, and Three.js r160 via native Import Maps), ensuring 60fps animations, instant loading, and zero build toolchain overhead.

2. AI Tools & Development Workflow

As an aspiring AI Executive, I leveraged state-of-the-art agentic AI tools to automate complex engineering stages, from visual reverse-engineering to shader mathematics and rapid debugging:

Phase 1: Autonomous Visual & DOM Inspection

Deployed autonomous browser agents with Playwright to inspect the reference site across desktop (1440×900) and mobile breakpoints, mapping out typography tokens (Sora & Inter), color tokens (#e3241b crimson, #0a0a0a deep ink), and CSS layout systems.

Phase 2: 3D WebGL & Shader Reconstruction

Reconstructed Three.js r160 geometry and custom GLSL shaders for the interactive globe and 700vh scroll-driven ocean voyage, solving complex camera spline interpolation, wave displacement, and ACESFilmic tone mapping.

Phase 3: Component Engineering & In-Memory CMS

Implemented modular client-side engines: dynamic SVG sprite injection, mouse-tracking 3D card tilt with radial glare, count-up animations, and a relational article database with instant live search and category filtering.

Phase 4: Version Control & Automated Deployment

Organized the codebase into a clean Git repository, pushed to GitHub under Premsai19/importnow-replica, and configured automatic deployment to GitHub Pages for instant live evaluation.

4. Key Interactive & 3D Engineering Highlights

  • Interactive 3D Trade Route Globe (assets/globe.js): Renders a high-fidelity Earth with custom atmospheric rim glow and ACESFilmic tone mapping. Shipping routes connecting Chinese manufacturing hubs (Shanghai, Yiwu, Guangzhou) to Indian ports (Nhava Sheva, Chennai, Hyderabad) are computed using 3D Bezier splines. 3D coordinates are dynamically unprojected onto 2D screen space to render responsive HTML pin badges with country flags.
  • Scroll-Driven Ocean Voyage (assets/voyage.js): Spanning a 700vh scroll container with sticky viewport positioning, the scene features procedural ocean waves (Three.js Water shader), a physical sky dome with Rayleigh/Mie scattering, a detailed container cargo vessel, rotating radar, and working harbor gantry cranes with trolleys and spreader cables that animate based on page scroll position.
  • Interactive Chinese Business License Plaque (#shanghai): A 3D perspective rotated Chinese business license plaque for Shanghai Shengqiao Chain Trading Co., Ltd., featuring authentic Songti typography, national emblem radial gradient, official seal stamp, and interactive mouse-tilt parallax.
  • Instant WhatsApp RFQ Integration: The quote inquiry form validates user inputs (Category, Quantity, Budget, and Specs) and directly compiles and URL-encodes a pre-filled WhatsApp message sent to +91 99897 24320.
